# 青野 · 创建球局与玩法 Demo（第三版：组员自记）

这是独立交互演示。只更新本目录，没有接入、修改或发布现有微信小程序。

## 打开

用浏览器打开 `dist/index.html`；若已开着此 Demo，刷新即可。所有样式、计算和交互已打包为一个 HTML 文件，无需服务或安装。沿用第二版浏览器存储，已有成绩保留；旧数据会补上身份与修改记录字段。

## 完整体验

1. **创建球局**：填写名称，选示例球场、前九 / 后九 / 18 洞、2–6 位球友，编辑昵称。
2. **选择玩法**：仅记分、个人比杆、两人比洞、四人两队比洞、标准积分、8421。
3. **详细规则**：个人或固定两人队；总杆或净杆；本轮让杆总数或逐洞让杆；正式规则或球友约定；抓鸟和 Skins 可选。
4. **确认开球**：查看本场完整约定与让杆摘要，然后开始。
5. **逐洞记分**：初始均为空。首位球友为创建者，可代记任意组员，已填部分即可保存；其他组员只改自己的成绩，不必等全组填齐。组员自己的记分项排在最前面。保存后更新成绩及计算结果。
6. **全组记分卡**：前九 / 后九切换；组员点自己的某洞可修改，其他球友仅供查看，创建者可代改。个人总杆、净杆或积分与进度分别呈现。
7. **本场结果**：按所选主赛显示成绩、杆数排名、积分排名或比洞结果；附加玩法单独展示。
8. **结束与恢复**：由创建者核对后结束本轮，成绩锁定。只有创建者可解锁，更正记录保留。刷新可恢复球局与演示身份。创建者在右上角“···”可创建新球局、填入未记球洞的示例成绩或重置。
9. **切换身份**：顶部“切换身份”可体验各组员。每人保留各自当前球洞；未保存修改会先提示，不能切换身份直接覆盖。
10. **修改记录**：记录操作者、时间、球洞、球友及改动前后值。组员自记与创建者代记都有记录；撤销也保留痕迹。记录弹窗显示最近 50 次操作，完整记录保存在本机。

## 实际支持的规则

| 项目 | 本版功能 |
| --- | --- |
| 人数与洞段 | 2–6 人；前九、后九、18 洞 |
| 仅记分 | 个人实际成绩，不排名 |
| 比杆 | 个人 2–6 人；4 / 6 人可组成 2 / 3 个两人队，各洞取较低杆数 |
| 比洞 | 2 人个人；4 人两队四球；领先多于剩余洞数提前结束；打满平局记 AS |
| 积分 | 标准定分式；8421；个人或两人队，队伍每洞取较高积分 |
| 让杆 | 本轮总数按示例 SI 分配；或逐洞填 0–3 杆；比洞总数先减最低值 |
| 封顶 | 个人比杆可选双倍 Par、Par+3、10 杆，净杆可选净双柏忌；实际杆数保留 |
| 打球约定 | 正式、小流氓、大流氓、自定义；出界、下水、长草、补救、找球、短推、捡球逐项确认 |
| 抓鸟 | 小鸟 1 点、老鹰 2 点、信天翁及更好 3 点；可选实际总杆 / 净杆 |
| Skins | 个人仅记分、常规比杆、积分；独自最低获点；并列滚存或作废 |
| 特殊状态 | 积分 / 封顶捡球、队友本洞不计；对手承认下一杆；自定义免推；比洞让洞 / 平洞 |

8421 的本版完整积分表：相对 Par ≤−3 为 16 分，−2 为 8 分，−1 为 4 分，0 为 2 分，+1 为 1 分，≥+2 为 0 分。这是可见的球友玩法约定，不冒充统一国际规则。

“小流氓”“大流氓”只作为个人约定模板名称，没有暗藏处罚表。用户必须逐项确认；自定义项要求填写处理说明。文字约定由人执行，应用不自动裁定违规或根据标签加罚杆。总杆已含罚杆。

未填和捡球分别保存；捡球不生成实际总杆。比洞让洞只改变洞结果，不伪造杆数。队友未填时团队成绩待确认；队友明确不计后才采用另一名队员的成绩。主赛与附加点数不混合。

Skins 从首洞连续结算；缺分、捡球或免推会暂停后续结算，不能凭其他人的成绩直接判胜。抓鸟仅根据实际完洞记录核实，免推、承认推杆和捡球不自动发奖。

## 组员权限

| 操作 | 创建者（首位球友） | 其他组员 |
| --- | --- | --- |
| 记分、修改、清空 | 全组任意组员 | 仅自己 |
| 独立保存 | 可只填部分组员 | 不等待他人 |
| 查看全组成绩、修改记录 | 可以 | 可以 |
| 结束本轮、解锁更正 | 可以 | 不可以 |
| 记录比洞让洞 / 平洞 | 代录双方确认结果 | 只查看 |
| 新建球局、填示例、重置本局 | 可以 | 不可以 |

切换身份是演示控制，不是真实账户权限。刷新后保留同一浏览器的模拟身份；其他手机、浏览器或标签页不构成真正的多人同步。

## 演示边界

球场、SI、球员、距离和自动填入成绩都是示例，不用于真实球场定位、测距或差点认证。所有操作在浏览器本地，没有多人实时同步、账户或云端连接。这版没有向现有小程序新增接口或改动其权限。本轮结束是代记核对，不冒充每位球员在线签字。正式赛事结果更正遵循赛事程序；此 demo 的解锁只展示本地纠错流程。

本版没有实现 Scramble、轮换击球、三方比洞或六人队际比洞；不提供未实现的虚假入口。6 人可体验个人比杆 / 积分 / 仅记分，或三支两人队的比杆 / 积分。
