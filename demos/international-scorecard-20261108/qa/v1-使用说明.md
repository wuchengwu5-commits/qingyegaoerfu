# 青野 · 国际赛事记分卡 Demo

这是独立的设计与交互参考，没有接入或修改现有小程序。

## 打开

用 Chrome 或 Safari 打开 `dist/index.html` 即可。无需安装、登录或启动服务；电脑显示设计说明和手机预览，小屏显示完整手机界面。演示所需样式和脚本均在这一个 HTML 文件中。

## 推荐体验顺序

1. 默认从第 10 洞开始，前九洞已填入示例成绩。
2. 点击某位球员后选择小鸟、标准杆、柏忌，或用加减调整杆数。数字是包含罚杆的本洞总杆。
3. 可以点击“全组填入标准杆”再逐人调整；这是明确填入操作，不会自动替空白记分。
4. 点击“保存本洞”，再切换“记分卡”“排行榜”，看合计和排名联动。
5. 在记分卡上点击某一洞，可返回修改；未保存的改动会有离开提醒。
6. 点击右上角“···”中的“载入完赛示例”，体验完整 18 洞和模拟交卡。模拟确认球员与记分员核对后，记分卡锁定。
7. “重新开始演示”只重置这个 demo 的数据。

## 设计取舍

- 个人总杆比杆赛，不让杆；不混入比洞赛和积分赛口径。
- 总杆、相对标准杆、完洞进度同时呈现，避免在进度不同的情况下只比较总杆。
- 前九 OUT、后九 IN、全场合计；未填用破折号显示，不计为 0 或标准杆。
- 红色圆圈：小鸟；双圆圈：老鹰或更好。蓝色方框：柏忌；双方框：双柏忌或更差。图形和文字共同表达，不只依赖颜色。
- 排名用 T 表示并列，E 表示平标准杆，F 表示本轮完赛。
- 四位同组球员可编辑；另外四名球员为固定示例数据。
- 适当放大数字并保持表格整齐，采用深绿、米白和少量金色，不复制任何赛事品牌。

## 边界

球员、赛事、球场及距离都是虚构示例。所有数据仅保存在当前浏览器的独立存储键 `qingye-international-demo-20261108-v1` 中；浏览器不支持本地存储时会提示，当前页面仍可操作。

模拟交卡不是实际签名或真实赛事提交。不包含多用户同步、官方差点认证、罚杆裁定、多轮赛事、净杆与比洞赛，也不连接现有小程序或云数据库。交卡后的真实赛事更正应按赛事委员会流程处理，本 demo 仅提供重新开始。
