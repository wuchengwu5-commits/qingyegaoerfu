# 青野高尔夫 H5 · V3.1

手机布局的本地可用版本。已接入全国公开球场目录与 V3.1 记分模块，沿用白色、淡绿、深绿按钮和圆角卡片风格。

## 查看

在项目根目录执行：

```sh
python3 golf-h5/server.py --port 8766
```

浏览器打开 http://127.0.0.1:8766/#/courses ，后台为 http://127.0.0.1:8766/manage/ 。这是当前电脑的本地地址。首次进入后台，由你设置首位管理员的登录名和密码，没有内置默认密码。

完整图片上传和内容管理需要运行上述管理服务。只静态托管 `dist` 时，内置球场和银涛来源图仍可查看，后台写入功能不可用。

## 体验顺序

1. 球场 → 按省市或名称查找 → 查看球场资料与洞段。
2. 在球场开始记分 → 选一个或两个九洞段 → 选择 1–4 位球友及各自发球台。
3. 选择快捷玩法或修改五项规则；需要净杆时显式设置让杆。SI 不完整时采用逐洞指定，不能自动猜测。
4. 确认开局 → 点击中间数字记Par、加减、技术记录 → 下一洞。每次确认立即保存，未填写的球友会提醒。
5. 本轮成绩 → 分开查看实际杆、主赛和附加玩法 → 检查并结束。
6. 已结束球局可填写原因更正，记录修订号与旧值；完整记分卡展示让杆、净杆和积分。
7. 我的 → 设置与数据 → 导出 JSON 备份或恢复。示例与个人模式分开保存。

## 实现范围

- 442 条球场/分场记录、940 个九洞段、8,460 个球洞、1,746 个发球台、34,201 条距离。覆盖31个省级地区，含港澳台；429条可直接记分，13条记分卡待补全。
- 仅记分、个人比杆、比洞、固定两人队四球、标准定分式及 8421。
- 总杆/净杆、手填本轮总让杆、逐洞指定、个人比杆封顶。
- 正式规则/自定义/大小流氓七项约定；Skins、拿骚、抓鸟、最近旗、最远开球。
- 捡球、跳洞、比赛作用范围、追加罚杆预览、撤销、历史更正、个人统计和规则快照。

计算由项目根目录 `shared-golf` 提供，与微信原生小程序使用相同文件。改共享逻辑后执行 `node tools/build-golf.mjs`；构建同时更新页面资源版本号，避免旧浏览器缓存混用新版模块。

记分时总杆按“本轮标准杆 + 已实际完洞的累计杆差”显示，例如Par72、目前+4显示76；未打完注明“按当前杆差”。逐洞实际记录、赛果和正式统计仍按实际完洞计算。

## 数据与限制

- `qingye.h5.demo.v3` / `qingye.h5.own.v3` 为本地存储；旧 `.v2` 键与 `.pre-v3` 备份保留。失败时停止保存，不覆盖原记录。
- 旧记录保留原始数值，规则不明和来源未确认时不进入严格统计；可逐轮补充当时规则并核对实际完洞来源。旧版默认推杆保持来源未知，不自动计入明确填写的均值。
- 页面已加载后无需网络记分；重新打开页面需要静态服务可用，本版未安装离线页面缓存。
- 数据保存在当前浏览器，未连接云端。不同浏览器/设备通过备份转移；接近存储上限时需导出备份。
- 全国资料采集于2026-10-23，长三角保留2026-10-19已核对版本；并非完整在营名录，营业状态和现行记分卡适用性待球会核实。码数不是 GPS 距离；SI 缺失或重复会阻止自动分配。
- 未生成官方差点、Course Rating、Slope Rating；没有多人实时联机、支付、天气、真实定位测距。
- 原始八张设计图未同步到当前项目，本版依据已确认的文字规范与现有素材继续实现。

## 2026-10-24 手机体验与反馈更新

新增首页品牌支持小条、球场指南（球道图与记分卡距离合并）、分组完整记分卡、反馈页面与后台回复、关于青野品牌介绍。手机触达、字号、弹窗、选择器和短屏记分同步优化。

使用 server.py / start.sh 启动后可体验完整反馈服务；仅打开静态 HTML 不提供反馈保存接口。前台入口 #/feedback、#/about，后台 /manage/ 的“用户反馈”仅管理员可访问。反馈存入 data/management.sqlite3，源码包不包含运行数据库、账户或会话。

详细说明见 ../deliverables/手机体验与新增功能-交付说明.md。新增页面目前是 H5，尚未移植微信原生页面。
