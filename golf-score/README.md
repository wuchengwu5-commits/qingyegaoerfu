# 青野 · 高尔夫记分微信原生小程序 V3.1

11 个原生页面，WXML + WXSS + JavaScript，无需 npm、云环境或后端。球场目录、图片和计算逻辑随包提供。H5 是另一个预览客户端，两者共用 `shared-golf` 规则层。

## 运行

1. 在微信开发者工具中导入本文件所在 `golf-score` 目录，入口是 `project.config.json`。
2. 使用自己的有效 AppID 或开发者工具提供的测试号。当前 `touristappid` 是占位，真机预览和发布需有效账号配置。
3. 编译后从「开启一场好球」选择球场、洞段、球友和玩法。无需云服务初始化。
4. 每台设备分别本地保存；手机和模拟器不会自动同步。

本次完成了计算、存储、页面事件自动测试；**尚未在微信开发者工具编译，也未完成微信真机验收**。

## 页面

首页、球场、创建球局、规则设置、逐洞记分、特殊情况/比赛事件、结果与记分卡、历史、统计、球友、我的。

- 球场支持省份及名称搜索，查看实际洞段、Par、SI、发球台距离、地址电话和资料来源。
- 一轮选一个或两个九洞段，可设18洞从第10洞出发。选择后九作为9洞时，本轮编号1–9，保留原球洞标识。
- 每人保存发球台、逐洞Par与SI快照。多人比较所需资料不匹配时拒绝开局，不静默替换。
- 五项设置包含记分方式、组队、让杆、判罚约定、附加玩法；可保存规则模板。
- 支持仅记分、比杆、比洞、四球、标准定分式、8421，总杆/净杆、个人封顶、Skins、拿骚、抓鸟及人工确认奖项。
- 总杆包含罚杆。罚杆分项不再次加总；追加罚杆会预览并同时更改两项。
- 未录入不是0杆。捡球/跳洞/认可下一杆分别记录；赛事让步有明确作用范围。
- 下一洞前提醒未记球友；可回洞、撤销最新操作。结束允许部分完成，缺分不自动判胜。
- 结果分开显示实际成绩、主赛、附加玩法；历史更正必填原因并保留修订。
- 统计分为正式实际成绩、自定义/封顶、旧版统计，并分开9洞和18洞。

## 数据及升级

当前存储 `greenGolf.v3`，启用标记 `greenGolf.activeVersion`。升级先保留 `greenGolf.v1` 原键及 `greenGolf.pre-v3` 副本，再迁移、校验、写入和验证可读。失败时可查看有效旧数据的只读视图，并在首页重试。

旧记录的罚杆不重复加总；未完整球局不补分；未知SI保持空白；旧版默认推杆不冒充用户实际填写。旧记录必须补充当时规则并核对实际完洞来源，才能满足严格统计条件。

「我的」可导出JSON文件、复制备份内容、分享备份文件或粘贴JSON恢复。恢复先校验，错误格式/未知版本不会替换现有库，导入前的库保留到 `greenGolf.beforeImport`。备份包含球友昵称与成绩。

## 共享源码与测试

共享源文件在项目根目录 `shared-golf`，本目录 `services/rules.js`、`catalog.js`、`service.js` 为构建副本。修改共享源后在项目根目录执行：

```sh
node tools/build-golf.mjs
node --test tests/scoring-v3.test.cjs tests/integration-v3.test.cjs tests/national-catalog.test.cjs golf-score/tests/core.test.js golf-h5/tests/*.test.cjs
python3 tools/verify-course-workbook.py
```

93 项自动检查通过，包含全国目录完整性、规格 T01–T44、4人18洞净杆+Skins、四球比洞+拿骚、个人9洞积分+奖项，以及改分、撤销、备份恢复、失败保护和迁移。页面事件测试模拟微信API，不等同于真机测试。

## 真机待验收

开发者工具编译；微信9/18洞全部交互；四人记分排版；小屏幕与键盘；关闭微信后恢复；设备存储空间不足；微信文件分享/恢复；本机权限与实际AppID。对有效SI的自动让杆，应先核实当前洞段和发球台的实际适用性。

## 素材与范围

442条全国公开球场／分场资料，含港澳台。原长三角65条保留2026-10-19版本，其余采集于2026-10-23；429条可按已取得记分卡开局，13条待补全。不是全部仍营业球场的认证名录。图片仍使用项目已有的统一风格照片，不代表各球场实拍。没有实时联机、官方差点认证、真实GPS、天气、支付与云同步。

全国目录详见 `../deliverables/全国球场目录-交付说明.md`。
