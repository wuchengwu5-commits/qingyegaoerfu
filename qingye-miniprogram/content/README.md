# 青野轮换文案库

首批 120 组原创文案，放松、治愈、想去打球、热爱运动各 30 组。每组包含固定搭配的标题与小字。

- `文案总览.md`：按主题阅读、审稿。
- `slogans.csv`：唯一编辑源，UTF-8 编码；`enabled` 为 1 时启用，改成 0 即停用。新增文案使用新编号，已有编号不要复用。
- `slogans.sqlite3`：SQLite 数据库交付件，包含 `themes` 与 `slogans` 表，可查询或导入其他管理系统；由 CSV 生成，不直接编辑。
- `slogans.json`：结构化导入文件。
- `../miniprogram/services/slogans-data.js`：自动生成的小程序内置数据，离线直接读取，不依赖服务端。

修改 CSV 后运行 `python3 qingye-miniprogram/build-slogans.py`，再运行 `python3 qingye-miniprogram/build-preview.py` 更新浏览器预览。小程序更新文案需要重新构建并发布；本轮未增加远程管理后台或自动下发服务。

展示规则：

1. 首页从全部 120 组选择标题与小字；球场页从“想去打球”30 组选择标题与小字；“我的”页从“治愈”和“热爱运动”60 组选择小字，保留页面名称“我的青野”。
2. 每个位置独立记住已展示编号，同一位置看完一整轮才重新随机，跨轮也避免连续相同。有限文案会循环，不能永久不重复。
3. 冷启动换一组；退到后台至少 60 秒后返回换一组。短暂切换、授权返回、站内切页、筛选、同步和刷新数据不切换。
4. 标题与小字一起选择，页面停留时不自动计时切换。
5. 展示历史独立于球局、账户与成绩；清除应用存储或换设备会重新开始。存储不可写时使用当前进程的内存历史，关闭后无法保证不重复。
6. 关于青野使用固定的品牌介绍；记分、球场资料、规则提示和按钮名称仍使用明确的功能文案。

写作约定：标题最多 16 字符、小字最多 34 字符；优先短句和具体画面，不编造实时天气、不承诺运动的治疗效果，也不以成绩制造压力。首页允许标题自然换行，兼容较长标题和小屏。
