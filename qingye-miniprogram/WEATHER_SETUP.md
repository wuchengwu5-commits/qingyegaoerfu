## 第一次开通（已确认使用和风天气）

1. 在[和风天气用户中心](https://id.qweather.com/)注册并登录，账号由小程序负责人持有；验证码、实名认证或付费选择由账号本人完成。先完成注册即可，再继续下面的配置。
2. 在控制台“项目管理”创建“青野高尔夫”项目，添加JWT凭据；所需公钥及云端私钥配置可在注册后继续完成。接口签名代码已实现，无需手工定期生成Token。[官方项目与凭据说明](https://dev.qweather.com/docs/configuration/project-and-key/)
3. 在控制台“设置”查看开发者ID和API Host，将账号信息配置到天气云函数。API Host可能含地区子域，例如`账号.xy.qweatherapi.com`，必须完整复制；不要照抄示例。[官方Host说明](https://dev.qweather.com/docs/configuration/api-host/)

费用以账号控制台显示为准，当前没有代用户购买套餐或充值。私钥只存放在本地安全位置和云函数配置，不发聊天、不放前端。

## 天气服务配置

采用和风天气当前的实时天气 v1：`GET /weather/v1/current/{latitude}/{longitude}?lang=zh`。不用即将弃用的 `/v7/weather/now`。

目标为小程序现有云环境 `cloud1-d7gketoi570d17f80`。函数目录为 `cloudfunctions/qingyeWeather/`，已部署并远程安装依赖。早期部署记录在 `../outputs/home-weather-2026-11-04/deployment-status.json`。2026-11-09 用户已创建和风项目并登记本机生成的公钥，账号配置已保存到现有云函数，真实签名验证通过。私钥位于已忽略的 `.local-secrets/qweather/ed25519-private.pem`（权限0600）；请保留现有密钥对，勿重新生成。

现有云函数已配置以下 JWT 环境变量，执行超时为15秒（上游请求8秒超时）。后续重建或迁移时沿用以下配置方式。**不要把密钥放进小程序 config.js、代码仓库或聊天记录。**

| 变量 | 内容 |
| --- | --- |
| `QWEATHER_HOST` | 账号专属 API Host，例如控制台给出的 `xxxx.xy.qweatherapi.com`，不要照抄示例 |
| `QWEATHER_API_KEY` | API KEY；与下面 JWT 方式二选一 |

推荐 JWT 方式，配置 `QWEATHER_HOST` 和以下四项，不需要 API KEY：

| 变量 | 内容 |
| --- | --- |
| `QWEATHER_KEY_ID` | JWT 凭据 ID |
| `QWEATHER_PROJECT_ID` | 和风项目 ID |
| `QWEATHER_DEVELOPER_ID` | 和风开发者 ID |
| `QWEATHER_PRIVATE_KEY` | Ed25519 PKCS8 PEM 私钥，可使用真实换行或字面量 `\n` |

JWT 仅在云函数内签名，有效期15分钟；身份认证头和上游原始报错不会返回到小程序。支持 API KEY 的请求头方式，密钥不进入 URL。上游主机限制为账号专属 `qweatherapi.com` 域名，不接收客户端 URL。

## 更新和展示规则

- 按首页展示的球场经纬度查询天气，不等待或上传手机当前位置。已标记 GCJ-02 的球场坐标先转为 WGS84，再发送两位小数的约1公里网格；未知坐标系沿用球场资料近似值。不向天气服务发送姓名、手机号或微信身份。
- 首页显示时查询；同一位置每小时更新一次，按返回数据的获取时间安排下一次更新，避免读到较旧的云端缓存后再多等一小时。位置网格变更立即换查询，回到首页复查缓存，网络恢复时重试，首页隐藏后停止定时器。
- 客户端与云端均采用1小时缓存；客户端持久保存最多8个球场网格的天气，重启后同步恢复，过期后台更新。并发请求合并，切换位置后丢弃旧请求结果。客户端失败后1分钟冷却。
- 使用接口返回的摄氏温度、天气现象、风向、蒲福风力等级。0°C、0级均为有效值；缺失风力显示“—”，不猜作无风。
- 接口原始数据保留16方位；首页简化显示，“西北偏北风”和“西北偏西风”均显示为“西北风”，其他斜向风同样省略偏向。
- 每小时更新失败时，最多再保留15分钟内同位置的旧数据，并明确显示“更新失败 · 上次天气”；获取时间超过75分钟的数据移除。拒绝定位、服务未配置、超时、异常数据均不显示编造数值。
- 天气区域仅展示，不绑定点击事件，不再弹窗或提供手动刷新。若上游 HTTP Last-Modified 存在且过期则拒绝数据。
- 按用户要求，首页卡片去掉 QWeather；在“我的 → 关于青野”说明末尾保留“天气数据来自和风天气。”，点击来源名称可复制官网链接。接口归因数组继续保留在返回数据中。
- 图标为统一的深绿色圆角线条，共10款，72×72透明 PNG，合计14562字节。矢量定义与生成程序在 `tools/build-weather-icons.cjs`，输出到 `miniprogram/assets/weather/`。当前资源文件总计191022字节，小于200000字节。

## 隐私配置

首页定位在本机缓存最近一次约百米精度的位置，最长7天，不保存轨迹；一小时内不重复请求 GPS，过期后后台更新，撤销授权清除缓存。天气请求使用公开球场坐标，不使用手机位置。代码中的隐私说明已更新；微信公众平台的《用户隐私保护指引》应与上述用途一致。云函数不把位置写入数据库或业务日志。
