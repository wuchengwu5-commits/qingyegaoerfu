# 青野小程序开发约定

## 球道图默认图层与每次更新验收（用户长期要求）

- 所有球场默认打开 GPS 卫星图，即使已有或刚更新精修图。默认进入、从全览选洞、换洞和重新进入时，不得因为图片存在或球场配置而自动加载精修图。
- 用户主动选择“精修图”后才加载当前洞；同一次页面浏览中可保留其手动选择，重新进入恢复 GPS。保留显式精修链接兼容，但普通球场、记分及旧书签入口不得自动注入精修参数。
- 初始选择统一使用 `miniprogram/services/map-layer.js`，禁止生成 `defaultFocusLayer: 'art'` 等球场级默认覆盖。更新图片、配准和地图模板不能改变此行为。
- 每次新增或修订 GPS / 精修图、更新地图模板、上传小程序前，均运行 `node tools/check-map-defaults.cjs`；失败先修复再交付。此命令自动检查已注册地图页面，新增球场也纳入。
- 默认入口检查必须省略 `layer` / `mode`，验证精修请求为 0；另验手动切图、切洞、全览、退出重进及失败重试。不能预先传 `layer=gps` 来替代默认检查，也不能因新增精修图而把期望改成默认精修。
- 微信验收从真实球场详情或记分入口进入本次球场；分别报告自动检查和微信实测结果。列表与详情的地图类型保持纯展示标签。

## 弹出框与选择器（用户长期偏好）

- 全部业务确认、提示、文本输入、操作菜单、日期/时间/选项选择统一使用青野自定义弹层。
- JS 使用 `miniprogram/services/dialog.js` 的 `modal`、`actionSheet`、`select`、`date`、`time`；页面选择入口使用 `qy-picker`，发球台使用 `tee-picker`（含颜色圆点）。
- 每个页面都挂载一个 `<qy-dialog class="page-dialog"/>`，包括分包页面；地图生成模板也必须保留弹层宿主。
- 不新增 `wx.showModal`、`wx.showActionSheet` 或原生 `<picker>`，不以这些 API 作为失败时的回退。
- 微信强制提供的授权、手机号授权、隐私协议、支付、系统设置、相册/文件等平台界面属于例外；不模拟系统授权。非阻塞的 toast/loading 提示可以保留。
- 延续浅色背景、绿色强调、圆角底部弹层、大点击区域；取消不修改数据，确认后才保存。详情见 `UI-DIALOGS.md`。
- 修改相关交互后运行 `tests/custom-dialogs.test.cjs`，检查返回页面、连开弹层、取消与输入的处理。

父目录 `sources/` 是只读同步资料，不得修改。

## 用户球局保存

- 新建个人球局必须带账号归属并进入 `personal-sync`；共同记分沿用原同步流程。私有备份不能自动邀请或向其他账号开放。
- 球局和活动历史不能截断为最近 50 条；接口使用稳定游标分页，客户端读取所有页。旧客户端数组响应兼容保留。
- 所有云写入以可信微信身份为准，并保留版本检查、重复请求保护、退出后的迟到响应保护；冲突保留本机副本。
- 未明确账号归属的旧记录须在小程序内确认后关联，不能猜测归属。已有账号关联的旧球局自动补同步。
- 操作历史使用 `round-archive` 保留修改差异与最近一次撤销状态，不重复备份每次操作的完整成绩表。
- 修改存储、账号、历史、开局或记分逻辑时运行 `tests/personal-data.test.cjs`、`tests/cloud-sync.test.cjs` 及相关回归；不得把仿真跨设备验证描述为两台真机验收。

## 记分一级入口与恢复（2026-11-13）

- `pages/play/index` 是第二个一级导航：正在记分时展示 `live-score`，球局列表是同页的另一状态；保留列表入口供新建、切换和结束。
- 进行中的球局通过 `services/score-entry.js` 打开一级记分；`ui.go('score', query)` 已统一转入该入口。成绩更正和冲突副本继续保留专用旧页面，勿自动恢复它们。
- 球场详情「开始记分」调用统一创建入口，先切到记分页，再打开 `create?fresh=1&course=...`，自动预选球场，不直接生成球局或跳入既有球局。
- 最近一组和当前球洞/球员按账号记录。普通重新进入可恢复；扫码、分享、授权和未完成的二级创建流程不得被自动跳转覆盖。
- 实时记分与原页面共用 `services/score-page.js` 和记分模板，避免复制两套记分逻辑。组件隐藏/销毁须停止轮询；快捷入口保留原保存、同步、权限及更正规则。
- 一级记分页在实时记分状态时，不因每次保存通知重新读取全部球局或请求赛事列表。
- 验收包含 `tests/score-entry.test.cjs`、个人保存/同步及记分回归；开发者工具模拟恢复不能描述成微信真机冷启动验收。
