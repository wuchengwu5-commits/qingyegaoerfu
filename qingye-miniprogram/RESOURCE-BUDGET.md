# 图片与音频资源长期约束

用户于 2026-11-04 明确要求：后续做图必须控制资源体积，避免微信开发者工具再次出现“图片和音频资源大小应不超过 200 K”未通过。

- **所有进入小程序代码包的图片与音频合计必须小于 200000 字节**。这是合计预算，不能理解为每张图片小于 200 K 即可。自动检查不得放宽或跳过。
- 新的竖屏背景先导出手机轻量 JPG，以单张不超过 80000 字节为目标；首页大图尽量保留 720 像素宽及纵向构图。Logo、图标保留透明 PNG。选择具体素材后仍须重新核算全部资源总量。
- 高清生成原图、候选图、拼图和多套季节背景保存在 `outputs/` 或 `deliverables/`，不能直接批量放进 `miniprogram/`。
- 更换内置背景时替换原文件，移出不再使用的资源；共享图标只放一份。若后续需要多图轮换，使用现有云资源机制加载并缓存，部署与接入另按用户授权执行。
- 编译前运行 `tests/package-quality.test.cjs` 中的 200000 字节媒体预算校验，并核对最终 ZIP 内未压缩的媒体文件总量；ZIP 压缩后的大小不能替代媒体预算。
- 素材交付说明应列出每张轻量图的尺寸与字节数，区分高清存档和小程序使用版。不得以放宽测试阈值代替实际优化。
