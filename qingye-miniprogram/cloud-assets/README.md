# 青野云资源

## 2026-11-05 背景主题

新增 `backgrounds-v1/` 版本目录，8 张手机背景均小于 80000 字节，总计 625213 字节，只通过云存储加载。数据库 `qy_backgrounds` 保存 `v1_主题ID` 记录，包括名称、季节、时段、云文件 ID、字节数、SHA-256 与启用状态，由独立云函数 `qingyeThemes` 读取。选择设置保存在用户本机，不混入球局或账号数据。

环境：`cloud1-d7gketoi570d17f80`（微信体验版）。

`media-v1/` 保存 230 个图片原件，云端目录同名。云端文件名由本地相对路径中的 `/` 替换为 `__`，如 `assets__spring-lake.webp`。`manifest.json` 记录路径、字节数及 SHA-256；云端文件已通过数量、大小和 MD5 校验。

页面背景和球场照片使用云文件 ID。地图通过 `wx.cloud.downloadFile` 下载并缓存到用户文件目录，单洞按区域请求图块。卫星图直连失败或超时时，客户端通过 `qingyeGpsMaps` 读取同一云文件。该入口仅提供球道图片的只读访问，图块沿用原图的地理坐标。更新此下载链路时需同时部署地图云函数和编译小程序代码。

轻量导航图标、字标和分享海报的小尺寸底图保留本地副本，包内媒体合计约 160 KiB；这些资源也已在云端备份。高清原件均在小程序上传根目录之外。

更新资源时使用新的版本目录，并重新核对校验清单后切换 `config.js` 的 `mediaRoot`，同时更新页面 WXML 与共享模板中的背景图 cloud 文件 ID。不要覆盖正在使用的版本导致缓存不一致。临时签名下载链接不能写入配置。
