# 球道图页面模板

本目录是银涛、佘山、天马、华凯、林克司、美兰湖名人赛、美兰湖尼克劳斯、旗忠共用的页面源模板。各分包的 `course-config.js` 提供球场、图片、洞位和来源，页面负责选洞、缩放、记分关联与展示。

`python3 tools/course-maps/build-template.py` 将模板复制到 9 个独立分包；`qingye-miniprogram/build-preview.py` 自动执行此步骤。不要直接编辑生成的页面文件。微信各分包不跨包 require 或引用图片，主包及每个分包均须低于 2 MiB。

## 两种数据模式

- **GPS 卫星图**：银涛、佘山。地理范围、参考起点、果岭多边形与中心均有独立坐标；保留定位精度及过期回调保护。距离是水平直线估算，未实地校准。
- **球道示意图**：本次新增 117 洞。设置 `diagram:true`，只提供图片像素尺寸和图片路径，使用 `diagram-core.js` 渲染；不提供地理范围或虚构果岭坐标，不请求定位，不显示测距。可选洞、前后切洞、缩放、拖动与查看卫星总览。

选洞一律按目录中的原始 sourceHoleId 关联。天马 27 洞使用老球场、天马球场、新球场三个独立九洞组，组内显示 1–9；页面内序号仍为 1–27。浏览不修改球局顺序和成绩。

## 新增球场

1. 独立配置 courseId、route、assetRoot、defaultMap、holes、overview、photo/atlas、来源与说明。每洞的键必须来自目录。
2. GPS 数据需要保留地理范围、坐标系、来源时间、起点、果岭轮廓、中心与裁切窗口。示意图只保留像素坐标；不能将其直接用于 GPS 测距。
3. 在 app.json、services/course-map-route.js 和构建名单中注册。只有校准数据模式才能在 gpsAvailable 中启用。
4. 核对所有洞号与分场、后九/反序开局映射、图片失败重试和过期回调、返回记分、手机尺寸以及包体。

新增五场的素材获取与构建：`fetch-five-guides.py`、`fetch-five-imagery.py`、`build-five.cjs`。逐洞来源及修正记录见 `outputs/shanghai-five-gps/import-manifest.json`。天马图册 A/B/C 实际分别为天马/新/老，必须按图片标题映射。天马场第 3 洞、华凯第 10 洞的原始误图已从独立公开图册补正。
