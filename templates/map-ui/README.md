# 青野手机球道图控件标准

2026-11-05 用户指定：后续球道图以天马连续 GPS／精修图页面为标准，替代旧银涛页面的控件布局方向。

- 左下方两行操作：GPS／精修图切换在上，切洞在下；“下一洞”显示文字、扩大点击区并使用深绿色主按钮。
- 右下方放大、缩小、定位；定位含十字准星图标和文字。单个导航操作至少 44px 高，左右操作区互不遮挡。
- 果岭中心数字放大至常规 40px，小屏为 35px；前后沿为 20px，小屏为 18px。地图上的分段距离标签为 14px。
- 按钮统一采用浅色半透明渐变、细白边框与轻阴影；选中项和主按钮使用青野深绿色。不要用大块工具栏遮挡球道。
- 保留底部安全区、地图来源署名与比例尺。所有点击区来自 `items()`，绘制使用同一份数据，避免出现按钮看得到却点不到的问题。
- 控件原型为本目录 `atlas-hud.js`；运行 `tools/course-maps/build-template.py` 同步到全部 9 个球场入口及连续 GPS 页面。所有旧版入口也使用本目录控件，禁止再单独维护一套按钮样式。

定位图标由画布绘制，不增加包内图片资源。调整界面不能改变地理坐标、测距算法、精修图配准和球局记录。

## 不同资料类型的显示

- 已有 GPS 坐标：显示果岭距离、定位、比例尺和地图署名。
- 未配准的精修／参考图：沿用同一套选洞、切图、缩放和切洞按钮；隐藏 GPS 距离、定位、指北针和比例尺。记分卡码数标明“记分卡”，底部明确标注不用于 GPS 测距。
- 待制作球洞：保留选洞、上一洞／下一洞和已有总览入口，不显示虚构距离或不可用定位。
- 旧入口通过 `hudOptions()` 传入实际可用能力，`updateHud()` 与 `drawHud()` 使用同一几何数据。切换地图不能改写记分洞、已保存起点或球局单位。

## 地图类型名称与入口提示（2026-11-06）

面向用户的地图类型只使用“GPS 卫星图”“精修图”。球场列表、球场详情使用 `services/course-map-route.js` 的 `mapInfo(courseId)`，不在页面按球场写特例。列表仅显示实际存在的类型；详情沿用相同标签，并显示已完成洞数。仅有卫星全览时显示“GPS 卫星图 · 仅全览”及复核提示，不宣称已有逐洞测距。无图球场不显示类型标签或空的详情入口。

新增球场需同步实际 `gpsCount`、`overviewAvailable`、`referenceCount`；例如天马已有 27 洞精修图。不要把路由占位当作有图，也不要从全部洞数推算已完成图片。地图切图控件同样使用上述两个名称；未配准精修图仍须明确说明不用于 GPS 测距。


## 整屏底图与宽屏（2026-11-06）

所有连续 GPS 页共用本目录 `atlas-background.js` 与 `atlas-viewport.js`。真实扩大范围的周边影像、高清 atlas 和地理遮罩使用同一相机；相机四角受周边范围约束，缩放、平移、旋转及尺寸变化不能露出纯色图边。周边图必须保留自身实际 extent、像素尺寸、bounds、来源与哈希，不能把原 atlas 缩小一份作为扩展范围。

低高度宽屏沿用天马视觉，将果岭中心及前后沿横向排列，GPS/精修切换与切洞在底部同一行，绘制与点击区域仍来自 `items()`。验收使用实际画布宽度覆盖长屏、横屏和平板。默认当前源为本目录；旧截图和旧预览项目不得覆盖本目录的较新版本。
